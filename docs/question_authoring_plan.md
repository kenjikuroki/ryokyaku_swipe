# Question Authoring Plan

- 対象: `ryokyaku_swipe`
- カテゴリ: `part1` から `part5`
- 基本方針: 既存公開50問は固定し、新規50問で各カテゴリ100問化する
- 作成単位: 内部では `30問作成 → 自己レビュー → 20問追加 → 横断レビュー` の順で進める
- 品質基準:
  - 1問1論点
  - 既存公開問題の意味・正誤は変えない
  - 新規問題だけで正誤比を調整し、最終的に各カテゴリ `正60 / 誤40` にそろえる
  - 台帳上で `approved` と `app_ready=yes` を確認してから JSON に反映する
- 反映順: 全カテゴリの台帳完成後に `assets/quiz_data.json` へ一括反映する
